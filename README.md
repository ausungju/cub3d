## 오류 발견
- 맵을 구성할 때, 맵 전체의 앞 또는 뒤에 스페이스나 탭이 들어가면 미니맵에서 탭 만큼 늘어나서 보임
- F 또는 C에서 숫자가 3개 밑이거나 넘으면 무시되고 실행됨
- 플레이어 생성시, 벽 옆에 통과할 경우에 대해 개선하고 싶은 부분은 플레이어의 이동속도를 0으로 나누어지지 않는 1.1311 같은 수로 바꾸고 싶은데 어딘지 모르겟어용,,, 왜냐면 플레이어 좌표에 0.5 ~ 0.99를 더하면 벽을 뚫고 세그폴트가 뜹니다. 그래서 0.001로 설정하였지만 벽 옆에 캐릭터가 생성되었을 때 벽 옆면을 보면 텍스처는 잘 생성 되었지만 플레이어가 벽쪽에 너무 붙어 있어요
